# Empirical Evaluation of Breast Cancer Detection Using Machine Learning and Deep Learning Techniques

This repository accompanies the research paper **“Empirical Evaluation of Breast Cancer Detection Using Machine Learning and Deep Learning Techniques”**, presented at **INDIACom 2025 — 12th International Conference on Computing for Sustainable Global Development**.

The study examines machine learning and deep learning approaches for breast cancer detection and classification, comparing datasets, preprocessing strategies, feature-selection techniques, model architectures, and reported performance across the literature.

## 🎯 Objective

Breast cancer diagnosis benefits greatly from early and reliable detection. This work evaluates how artificial intelligence techniques can assist breast cancer classification by studying:

- Machine learning approaches
- Deep learning architectures
- Image-based and tabular breast cancer datasets
- Data preprocessing and feature-selection methods
- Transfer-learning techniques
- Classification performance across different experimental settings

The study focuses on the effectiveness, strengths, and limitations of contemporary ML and DL methods used for breast cancer detection.

---

## 🧠 Methodology

The evaluated workflow broadly consists of:

1. **Dataset acquisition**
2. **Data preprocessing**
3. **Feature extraction and/or feature selection**
4. **Training and testing split**
5. **Model training**
6. **Classification**
7. **Performance evaluation**

Breast cancer cases are evaluated for classification into normal and abnormal categories, with abnormal cases further considered in terms of benign and malignant findings.

---

## 📊 Evaluation Metrics

The reviewed and evaluated approaches use common classification metrics such as:

- Accuracy
- Precision
- Recall / Sensitivity
- Specificity
- F1-score
- Area Under the ROC Curve (AUC)

These metrics provide a broader assessment than accuracy alone, especially for medical classification tasks.

---

## 🗂️ Datasets Discussed

The study examines breast cancer research using several widely used public datasets and imaging collections, including:

- CBIS-DDSM
- Mini-DDSM
- INbreast
- BreakHis
- IRMA
- Wisconsin Breast Cancer Dataset
- Wisconsin Diagnostic Breast Cancer Dataset
- Large histopathology image datasets

The datasets cover multiple data modalities, including mammography, histopathology, and numerical diagnostic features.

---

## 🔬 Representative Models and Approaches

The paper surveys and compares a wide range of machine learning and deep learning techniques, including:

### Machine Learning

- Support Vector Machine
- Random Forest
- K-Nearest Neighbors
- Decision Trees
- Logistic Regression
- Naive Bayes

### Deep Learning

- Convolutional Neural Networks
- ResNet
- Inception
- MobileNet
- Xception
- EfficientNet

### Hybrid Approaches

Several reviewed studies combine deep feature extraction with traditional machine learning classifiers or dimensionality-reduction methods.

---


## 💡 Main Takeaways

- Deep learning can automatically learn discriminative features from medical images.
- Transfer learning is particularly useful when medical datasets are limited.
- Classical machine learning remains competitive on structured breast cancer datasets.
- Data preprocessing and feature selection can significantly affect model performance.
- Hybrid ML-DL approaches can combine complementary strengths of both paradigms.
- Performance values across different papers should not be compared without considering dataset and experimental differences.
- Generalizability, interpretability, and robust clinical validation remain important research challenges.
